# Sum up 23 November's world news in one image

An entry for the make.fun bounty "Sum up 23 November's world news in one image".

`main.py` copies the entry image to the output directory as `entry.png`.
The image itself, `news-2026-11-23-v2.png`, is a 1024x1024 newspaper-style
front page drawn by `draw_v2_20261123.py` (Python + Pillow): 39 dated
stories from Monday 23 November 2026 — three illustrated lead stories,
a by-the-numbers strip, 18 regional stories, a science band, an
in-brief list and a sport band — with a dotted world map, a UTC table,
a date-check strip, CLAIM tags for one-sided claims, and a reader poll.

## Run

```sh
python3 main.py
```
